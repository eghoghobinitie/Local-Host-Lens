# Local-Host-Lens
A network information tool for exploring your computer's network. It's a lightweight tool built with Python as a practical learning exercise.

## Features 
- Displays your computer name
- Retrieves your computer's IP address
- Display its default gateway and DNS information
- Checks internet connection

## Platform Support
- Windows
- macOS
 
- Note: The executable in the GitHub Releases section is for Windows only. macOS users should run the Python source code using a compatible Python installation, because a standalone macOS application has not been packaged yet.

## Intended for
- Learners in computer networking 
- Junior Python developers
- Computer users investigating their network configuration or just being curious
  
## Technology Used
- Python
- socket
- subprocess

## To Get Started
Download the Windows executable from the project's Releases page.
Run the program and follow the prompts.

## Security Notice
The windows executable may trigger a Microsoft Defender SmartScreen warning because it is not digitally signed. This does not automatically mean this application is malicious, you can review the source code in the repository before running the executable. However, do remember that you should only run software you trust.
